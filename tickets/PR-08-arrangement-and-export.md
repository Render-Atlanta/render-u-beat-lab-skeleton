# PR-08 - Arrangement + export

**Type:** Feature  
**Depends on:** PR-02, PR-07

## Scope

- Add arrangement sections: intro, main, variation, outro.
- Let users mute/unmute lanes per section.
- Export project JSON.
- Stretch: offline render to WAV.

## Acceptance criteria

- Users can create a four-section beat without leaving the page.
- Exported JSON can recreate the project.
- WAV export is treated as stretch unless browser support is stable.

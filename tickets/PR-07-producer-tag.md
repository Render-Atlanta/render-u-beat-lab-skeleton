# PR-07 - Producer tag

**Type:** Feature  
**Depends on:** PR-01

## Scope

- Text-based producer tag using browser speech synthesis as the first pass.
- Optional recorded tag if microphone spike is complete.
- Add simple effects: pitch-ish playback, delay, and filter.
- Trigger tag at intro or manually.

## Acceptance criteria

- User can type a tag and hear it.
- Tag has an obvious on/off state.
- App remains usable when speech synthesis is unavailable.

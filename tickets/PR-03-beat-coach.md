# PR-03 - Beat coach learning layer

**Type:** Feature  
**Depends on:** PR-01

## Context

The instructor does not need to be a producer for the app to teach basic beat
structure.

## Scope

- Explain kick, snare, closed hat, and open hat in plain English.
- Add style cards with BPM, swing, and common feel notes.
- When users edit a pattern, describe density and pocket changes.
- Add "try this" prompts for each style.

## Acceptance criteria

- Each style teaches one concept without music jargon overload.
- Copy fits compact panels on mobile and desktop.
- Tests cover density summaries and instrument descriptions.

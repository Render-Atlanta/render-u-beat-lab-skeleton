# PR-27 — Clap + 808 Lanes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two curated instrument lanes — `clap` and `808` — to the beat lab so they appear in the grid, play in all three engines, ship with tasteful per-style defaults, and round-trip through pattern/URL/project serialization, without breaking the style-fidelity model.

**Architecture:** The lane set is currently a hard-coded 4-way union (`kick | snare | hat | openHat`) threaded through types, ordered lists, `Record<InstrumentId, …>` literals, both audio engines, the WAV renderer, and the style-fidelity feature model. We widen the union to 6 lanes driven by a single ordered list (`INSTRUMENT_IDS`), add real synth/sample voices, give every style preset a sparse tasteful clap/808 placement, and add backward-compat so 4-lane URLs/projects still load (new lanes default empty). Style-fidelity is deliberately kept measuring only the 4 core drum lanes by parameterizing the PCM renderer with a lane list, so the committed `styleProfiles.generated.ts` goldens never drift.

**Tech Stack:** TypeScript, React 19, Vite, Vitest, Web Audio API, Tone.js.

## Global Constraints

- **Lane set stays deliberately small.** Exactly two new lanes: `clap` and `808`. No open-ended instrument list. (Per ticket: Groove Pizza cut tracks to reduce option paralysis.)
- **New lane ids, in canonical order:** the ordered lane list is `["kick", "snare", "hat", "openHat", "clap", "808"]`. The `808` id is the string `"808"` (quoted in every object literal and union).
- **`808` is the app's bass** at a single default pitch in this ticket. Per-step pitch is the follow-up PR-31 — do **not** add pitch selection here.
- **Determinism:** no `Math.random()` / `Date.now()` in tests or generated artifacts. Kit one-shots are already generated (`public/kit/clap.wav`, `public/kit/808.wav`) by `scripts/generate-kit.ts` — do not regenerate or modify them.
- **Style-fidelity goldens (`src/lib/styleProfiles.generated.ts`) must NOT change.** The drift-guard test (`styleFidelityHarness.test.ts`) requires score ≥ 0.98 against committed goldens. Keep fidelity rendering/feature-extraction on the 4 drum lanes only.
- **Backward compatibility (mirrors the PR-25 `source` pattern):** older 4-lane serialized patterns (URL) and 4-lane project JSON must still load, with `clap`/`808` defaulting to empty (all-false) rather than erroring.
- **Gate command for every task:** `npm run check` (runs hygiene + scripts typecheck + full vitest). Must be green before a task is considered done. New lanes must never make an existing test fail without that test being intentionally updated in the same task.

```ts
const LEGACY_LANE_ORDER: InstrumentId[] = ["kick", "snare", "hat", "openHat"];

export function deserializePattern(value: string): Pattern | null {
  const rows = value.split(".");
  const order =
    rows.length === INSTRUMENT_ORDER.length
      ? INSTRUMENT_ORDER
      : rows.length === LEGACY_LANE_ORDER.length
        ? LEGACY_LANE_ORDER
        : null;
  if (!order) {
    return null;
  }

  const empty = () => Array.from({ length: 16 }, () => false);
  const pattern = Object.fromEntries(
    INSTRUMENT_ORDER.map((id) => [id, empty()]),
  ) as Pattern;

  for (let i = 0; i < order.length; i += 1) {
    const row = rows[i];
    if (!/^[01]{16}$/.test(row)) {
      return null;
    }
    pattern[order[i]] = row.split("").map((cell) => cell === "1");
  }

  return pattern;
}
```

(`serializePattern` already iterates `INSTRUMENT_ORDER`, so it now emits 6 groups automatically.)

```ts
  function playClap(time: number, accent = 1) {
    // Three quick band-passed noise bursts — the classic clap stagger.
    const offsets = [0, 0.011, 0.022];
    for (const offset of offsets) {
      const noise = createNoiseBuffer(0.09);
      const source = context.createBufferSource();
      const filter = context.createBiquadFilter();
      const gain = context.createGain();
      source.buffer = noise;
      filter.type = "bandpass";
      filter.frequency.value = 1600;
      filter.Q.value = 0.7;
      const at = time + offset;
      gain.gain.setValueAtTime(0.4 * accent, at);
      gain.gain.exponentialRampToValueAtTime(0.001, at + 0.09);
      source.connect(filter).connect(gain).connect(master);
      source.start(at);
    }
  }

  function play808(time: number, accent = 1) {
    // Tuned sub-sine with a short downward glide and long decay — the bass.
    const osc = context.createOscillator();
    const gain = context.createGain();
    osc.type = "sine";
    osc.frequency.setValueAtTime(80, time);
    osc.frequency.exponentialRampToValueAtTime(55, time + 0.08);
    gain.gain.setValueAtTime(0.7 * accent, time);
    gain.gain.exponentialRampToValueAtTime(0.001, time + 0.5);
    osc.connect(gain).connect(master);
    osc.start(time);
    osc.stop(time + 0.55);
  }
```

```ts
function readPattern(value: unknown, errors: string[], path: string): Pattern | null {
  if (!isRecord(value)) {
    errors.push(`${path} must be an object.`);
    return null;
  }

  const empty = () => Array.from({ length: 16 }, () => false);
  const entries = INSTRUMENT_ORDER.map((instrument) => {
    const row = value[instrument];

    // Backward-compat: a lane absent from an older project loads as empty.
    if (row === undefined) {
      return [instrument, empty()] as const;
    }

    if (!Array.isArray(row) || row.length !== 16) {
      errors.push(`${path}.${instrument} must be an array of 16 booleans.`);
      return null;
    }

    if (row.some((step) => typeof step !== "boolean")) {
      errors.push(`${path}.${instrument} must contain only booleans.`);
      return null;
    }

    return [instrument, [...row]] as const;
  });

  if (entries.some((entry) => entry === null)) {
    return null;
  }

  return Object.fromEntries(entries as Array<readonly [InstrumentId, boolean[]]>) as Pattern;
}
```
